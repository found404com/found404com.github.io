Drop In サポート プライバシーポリシー 利用規約

プライバシーポリシー

更新日： 2026年10月11日

1. 概要

Drop In は、iPhone で動画を録画し、Apple Watch から録画を操作するための iOS および Apple Watch アプリです。本アプリはユーザーのデバイス上でローカルに動作するように設計されており、アカウントを必要としません。

本プライバシーポリシーでは、Drop In がアクセスする可能性のある情報、その利用方法、およびユーザーが利用できる選択肢について説明します。

2. カメラ、マイク、写真の権限

Drop In はプレビュー、動画撮影、任意の参加者認識のためにカメラへのアクセスを、音声録音のためにマイクへのアクセスを求めます。権限は iOS の設定で変更できます。アプリ内のマイクミュート機能は Pro の機能です。

動画の保存や Pro の自動保存を有効にする際に、「写真」へのアクセスを求めます。アルバムを指定しない保存では追加のみの権限を使います。対応するアルバムへの保存では、その検索や作成のために読み取りと書き込みの権限が必要になる場合があります。アルバム名にはアプリ内のアルバム名や参加者名が含まれることがあります。

3. 動画とローカルギャラリー

Drop In で録画された動画は、ユーザーが別の場所に保存または共有することを選択しない限り、アプリ内にローカル保存されます。ローカルギャラリーには、動画、サムネイル、長さ、保存状態、アルバム割り当てが保存される場合があります。

ユーザーが録画する動画や音声には、ユーザーまたは他者に関する個人情報、例えば顔、声、場所、周囲の環境、活動などが含まれる場合があります。何を録画、保存、共有するかについてはユーザーが責任を負います。

4. アルバムと設定

Drop In は、録画開始までの遅延、録画時間の上限、カメラ品質、フォーカスモード、マイク設定、省エネルギーモード、画面をスリープさせない設定、音量ボタンでの開始設定、自動保存設定、アルバム名、絵文字バッジ、表示状態、順序、選択中のアルバムなどのアプリ設定をデバイス上に保存する場合があります。

5. Apple Watch リモートコントロール

Drop In の Watch アプリは、iPhone アプリのリモートコントロールとして動作します。この機能を提供するために、Drop In は iPhone と Apple Watch の間で、録画状態、接続状態、カウントダウン、経過時間、残り時間、選択中のアルバム、表示中のアルバム一覧、触覚フィードバック設定、リモート操作コマンドを同期する場合があります。

6. グループトレーニングと顔テンプレート

任意の Pro 機能であるグループトレーニングは、iPhone 上の Apple Vision と AuraFace を使って新しく撮影した動画を参加者に関連付け、個人別ギャラリーを表示します。ローカルプロフィールには名前、任意の絵文字と色、識別子、日時、有効状態、撮影設定、モデルのバージョン、数値形式の顔テンプレート（埋め込みベクトル）が含まれます。

スキャン画像や切り抜いた顔画像はメモリ内で処理され、参加者の写真としては保存されません。ただし、録画した動画やサムネイルには顔が映ることがあります。参加者名やテンプレートを認識サービスに送信することはありません。認識は誤る場合があります。これはギャラリー整理機能であり、生体認証、本人確認、なりすまし防止機能ではありません。顔の登録前に参加者の同意を得てください。

7. 任意のモデルとネットワーク通信

AuraFace のモデルファイルは、ダウンロードを明示的に確認した後にのみ HTTPS で取得します。モデル画面を開いたり更新したりすると、その確認前にモデル情報を記載したマニフェストを取得する場合があります。これらのリクエストには動画、顔画像、テンプレート、参加者名は含まれません。

マニフェストやモデルを配信するサーバーは、IP アドレス、時刻、要求されたファイル、HTTP ヘッダーなどの技術情報を受け取り、アクセスログを保存する場合があります。モデルファイルや実行時キャッシュは端末に保存されます。インストール後の認識はローカルで行われますが、ダウンロード、更新、利用可否の確認にはインターネット接続が必要な場合があります。

マニフェストとモデルは GitHub Releases および GitHub のダウンロード基盤から配信されます。技術的なリクエストの取り扱いについては、GitHub のプライバシーに関する声明をご覧ください。

8. Apple が管理する購入

Pro の支払いは App Store を通じて Apple が処理します。Drop In は、製品識別子、購入の有効性、サブスクリプションの期限や取り消し状態などの StoreKit 情報と、端末に保存した Pro 状態を使い、機能を有効化・復元します。アプリが支払いカード情報を受け取ることはありません。Apple は独自のプライバシー方針に従って購入情報を処理します。

9. サポートと法的情報のウェブサイト

これらのサポートと法的情報のページは GitHub Pages で公開しています。GitHub はセキュリティ目的で訪問者の IP アドレスを記録します。GitHub のプライバシー声明をご覧ください。Apple のヘルプリンクを開くと、独自のプライバシー方針が適用される Apple のサイトに移動します。

10. 情報の利用方法

情報は、カメラプレビュー、録画、カウントダウン、自動停止、ローカルギャラリー、アルバムフィルター、動画再生、共有、写真への保存、Watch リモートコントロール、触覚フィードバック、サウンド、エラーアラート、およびユーザーが選択して使用するアプリ設定を提供するために使用されます。

11. ローカル処理

Drop In はアプリ用アカウントを必要とせず、独自のクラウドギャラリーも提供しません。動画、音声、アルバム、設定、参加者プロフィール、顔テンプレートは端末で処理され、処理のために開発者へアップロードされません。ただし、ネットワーク通信が一切ないという意味ではありません。モデルの配信と Apple の購入処理については上記を、書き出し、システムバックアップ、サポートメールについては下記をご覧ください。

12. 共有とエクスポート

共有や「写真」への保存では、選択した保存先に動画が送られます。共有ファイル名や対応する「写真」アルバム名には、参加者名やアルバム名が含まれる場合があります。「写真」、iCloud 写真、端末バックアップ、その他の保存先は、ユーザーの設定と各サービスのプライバシー方針に従ってデータを保存・同期することがあります。Drop In はこれらのコピーを管理しません。

13. データの共有および販売

Drop In は録画、アルバム、設定、参加者プロフィール、顔テンプレートを販売せず、広告やプロファイリングのために共有しません。認識テンプレートはローカルギャラリーの整理に使い、広告には使いません。

14. 分析および診断

アプリには広告 SDK や第三者の分析 SDK を組み込んでいません。Apple または OS が、システムのプライバシー設定に従い診断やクラッシュ情報を提供する場合があります。これは録画された動画とは別の情報です。

15. データの保持

削除操作は「設定 → プライバシー → 参加者データ」から利用できます。Pro が有効でない場合や顔モデルが未インストールの場合も、この画面を開けます。

ローカルの録画、設定、プロフィール、テンプレートは、それらまたはアプリを削除するまで保存されます。「参加者を管理」では個別のプロフィール、または全参加者とテンプレートを削除できます。参加者を削除すると既存の動画の関連付けが解除されますが、動画自体は削除されません。ダウンロード済みモデルと Core ML キャッシュには、それぞれ削除操作があります。グループトレーニングをオフにしたり Pro を解約したりするだけでは、これらのファイルは消えません。

動画はギャラリーから、書き出したコピーは「写真」などの保存先から個別に削除してください。アプリの取り除きではなく削除を行うとローカルデータが削除されますが、バックアップや書き出したコピーは残る場合があります。削除のヘルプをご覧ください。

16. 子ども

Drop In は、現地法で定められた年齢に満たず、親の同意なしに録画アプリの使用、App Store ダウンロードの管理、または録画への同意を行えない子どもの使用を意図していません。

17. セキュリティ

Drop In は iOS、watchOS、および写真が提供するプラットフォーム保護を使用します。ただし、いかなるデバイスまたはソフトウェアシステムも完全な安全性を保証することはできません。ユーザーは自身のデバイス、写真ライブラリ、共有した動画を適切に保護する必要があります。

18. 本ポリシーの変更

当社は、本プライバシーポリシーを随時更新することがあります。更新後の版は、新しい発効日とともにこのページに掲載されます。
