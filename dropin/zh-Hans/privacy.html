Drop In 支持 隐私政策 服务条款

隐私政策

更新日期： 2026年10月11日

1. 概述

Drop In 是一款 iOS 和 Apple Watch 应用，可在 iPhone 上录制视频，并通过 Apple Watch 控制录制。本应用设计为在您的设备本地运行，不需要账户。

本隐私政策说明 Drop In 可能访问哪些信息、如何使用这些信息，以及您拥有哪些选择。

2. 相机、麦克风和照片权限

Drop In 请求相机权限，用于预览、视频录制及可选的参与者识别；请求麦克风权限，用于录制声音。您可在 iOS 设置中更改权限；应用内的麦克风静音开关是 Pro 功能。

保存视频或开启 Pro 自动保存时会请求“照片”权限。不指定相册时，仅使用添加权限。保存到对应相册可能需要读写权限，以查找或创建该相册；相册名称可能包含应用内的相册名称或参与者姓名。

3. 视频和本地图库

使用 Drop In 录制的视频会保存在应用本地，除非您选择将其保存或分享至其他位置。本地图库可能存储视频、缩略图、时长、保存状态和相册分配信息。

您录制的视频和音频可能包含您或他人的个人信息，例如面孔、声音、地点、周围环境或活动。您需要对自己选择录制、保存或分享的内容负责。

4. 相册和设置

Drop In 可能在您的设备上存储应用设置，包括录制延迟、时长限制、相机质量、对焦模式、麦克风设置、省电模式、保持屏幕常亮设置、音量键开始设置、自动保存设置、相册名称、表情徽章、可见性、顺序和所选相册。

5. Apple Watch 遥控

Drop In Watch 应用是 iPhone 应用的遥控器。为了提供此功能，Drop In 可能会在您的 iPhone 和 Apple Watch 之间同步录制状态、连接状态、倒计时、已用时间、剩余时间、所选相册、可见相册列表、触觉反馈设置和遥控命令。

6. 团体训练与人脸模板

可选的 Pro 团体训练功能在 iPhone 上使用 Apple Vision 和 AuraFace，将新录制的视频关联至参与者并显示个人图库。本地参与者资料包括姓名、可选表情及颜色、标识符、日期、启用状态、拍摄设置、模型版本和数值形式的人脸模板（嵌入向量）。

扫描画面及人脸裁剪图像在内存中处理，不会保存为参与者照片。不过，您录制的视频及其缩略图仍可能包含人脸。参与者姓名及模板不会发送至识别服务。识别可能出错：这是图库整理功能，不是生物识别身份验证、身份核验或防伪冒保护。注册人脸前，请取得参与者同意。

7. 可选模型与网络请求

AuraFace 模型文件仅在您明确确认下载后才通过 HTTPS 下载。打开或刷新模型页面时，可能在确认前请求描述模型的清单文件。这些请求不包含您的视频、人脸图像、模板或参与者姓名。

提供清单或模型的服务器会收到 IP 地址、时间、请求的文件及 HTTP 标头等技术信息，并可能保留访问日志。下载的模型文件及运行时缓存保存在设备上。安装后，识别在本地运行；下载、更新或检查模型可用性可能需要网络连接。

清单和模型通过 GitHub Releases 及 GitHub 的下载基础设施提供。技术请求的处理方式请参阅 GitHub 隐私声明。

8. 由 Apple 管理的购买

Apple 通过 App Store 处理 Pro 付款。Drop In 使用 StoreKit 产品和交易信息，例如产品标识符、购买有效性、订阅到期或撤销状态，以及本地缓存的 Pro 状态，来解锁或恢复功能。应用不会收到您的支付卡详细信息。Apple 按其自身的隐私规则处理购买信息。

9. 支持与法律信息网站

这些支持与法律信息页面由 GitHub Pages 托管。GitHub 会出于安全目的记录访客的 IP 地址。请参阅 GitHub 隐私声明。打开 Apple 帮助链接会进入 Apple 网站，其自身的隐私规则适用。

10. 信息用途

信息用于提供相机预览、录制、倒计时、自动停止、本地图库、相册筛选、视频播放、分享、保存到“照片”、Watch 遥控、触觉反馈、声音、错误提醒以及您选择使用的应用设置。

11. 本地处理

Drop In 不要求注册应用账户，也不提供自有云端图库。视频、音频、相册、设置、参与者资料及人脸模板在设备上处理，不会上传给开发者进行处理。这不代表应用不发送任何网络请求：模型分发及 Apple 购买见上文；导出、系统备份及支持邮件见下文。

12. 分享和导出

分享或保存到“照片”会将视频发送至您选择的目的地。分享文件的名称及对应的“照片”相册名称可能包含参与者姓名或相册名称。“照片”、iCloud 照片、设备备份及其他目的地可根据您的设置及各自的隐私规则保存或同步数据。Drop In 无法控制这些副本。

13. 数据共享与出售

Drop In 不出售您的录制内容、相册、设置、参与者资料或人脸模板，也不将其用于广告或画像分析而分享。识别模板用于整理本地图库，而非广告。

14. 分析与诊断

应用未集成广告或第三方分析 SDK。Apple 或操作系统可能依据您的系统隐私设置提供诊断和崩溃信息；这些信息与您录制的视频是分开的。

15. 数据保留

请打开“设置 → 隐私 → 参与者数据”使用删除控件。即使没有 Pro 或未安装人脸模型，仍可访问此入口。

本地录制内容、设置、参与者资料和模板会保留至您删除它们或删除应用。在“管理参与者”中，您可删除单个资料或全部参与者及模板。删除参与者会解除现有视频与该参与者的关联，但不会删除视频。已下载模型和 Core ML 缓存分别提供删除控件。关闭团体训练或取消 Pro 本身不会清除这些文件。

请在图库中删除视频，并在“照片”或其他目的地分别删除导出副本。“删除 App”（而非保留数据的“卸载 App”）会移除本地应用数据；备份和导出副本可能仍会保留。请参阅删除帮助。

16. 儿童

Drop In 不面向未达到当地法律要求、且不能在未经父母同意的情况下使用录制应用、管理 App Store 下载或同意录制的儿童使用。

17. 安全

Drop In 使用 iOS、watchOS 和“照片”提供的平台保护机制。然而，没有任何设备或软件系统可以保证绝对安全。您应妥善保护自己的设备、“照片”图库和已分享的视频。

18. 政策变更

我们可能会不时更新本隐私政策。更新后的版本会发布在本页面，并标明新的生效日期。

19. 联系方式

如有隐私问题或关于支持邮件的请求，请联系 brazier_jests8l@icloud.com。您联系我们时，我们会收到您的邮件地址、消息及附件，以处理请求。请勿发送人脸模板或敏感录制内容。我们无法远程访问或删除仅存于您设备上的数据。
